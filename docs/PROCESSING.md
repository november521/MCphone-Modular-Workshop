# 九类 App 与后台加工

本轮版本：`0.3.0-alpha.1`。原有工作台、锻造台、铁砧、切石机，加上织布机、制图台、砂轮、熔炉、酿造台，共九类。高炉、烟熏炉和附魔台按本轮要求暂缓。

## 玩法

- 每个 App 首次购买消耗一个对应原版方块，按玩家永久解锁。打开时须携带手机或平板。
- 七种即时工作站使用原版菜单和关闭返还；铁砧沿用原来的永久、不损坏规则。
- 熔炉和酿造台各有独立库存；同一玩家在当前存档中的所有手机／平板共享这两份库存，不会因更换手机复制材料。
- 关闭加工界面不返还或清空内部材料。玩家在线且存活时按服务器 tick 加工，不依赖区块加载，也不要求一直拿着手机。
- 离线或等待复活时暂停，不根据现实经过时间补算；复活、换维度或重新登录后继续。
- 卸载 App 保留内部库存，再次安装后仍可取回。死亡不掉落这两份虚拟库存。
- 熔炉使用当前数据包熔炼配方及目标平台燃料规则，产物取出时生成经验球并解锁配方；满格或不兼容输出不能再消耗原料。
- 酿造台使用当前原版／加载器酿造表；一次消耗一个原料，最多处理三瓶；烈焰粉提供 20 次燃料，单次 400 tick。更换原料或失去有效配方会取消当前批次，已消耗燃料不返还。
- 空桶等燃料余留物留在燃料槽。酿造原料的余留物优先留在原料槽；原料仍有剩余时放回玩家背包，背包满则掉在玩家位置。

## 实现与存储

`processing/` 负责共享库存、加工状态与文件保存；`ProcessingPlatform` 仅适配各版本配方、燃料、物品序列化与加载器事件；`ProcessingEvents` 接入 tick、保存、退出及停服事件。

使用 `FurnaceMenu`、`BrewingStandMenu` 的原版槽位与同步协议；服务端控制真实库存及进度。客户端仅选择 App，不能上报加工完成或生成产物。
不放临时世界方块，也不把原版方块实体绑定到玩家所在方块上调用 tick。

保存路径：`<世界存档>/mcphone_workshop/<UUID>.json`，格式版本 1。现代版本使用注册表感知的原版 ItemStack Codec；Forge 1.20.1 使用原版保存 NBT 的 SNBT 字符串，保留 Forge 能力与 NBT 数组类型。
该文件属于世界存档，应和玩家数据一起备份；不承诺跨 Minecraft 版本直接复制文件。

库存变动标记待保存，每 200 tick 自动保存，关闭界面、原版玩家保存、退出及正常停服也会保存。
写入同目录临时文件后原子替换；写入失败记录错误并保留内存状态重试。读取错误或不支持的格式拒绝打开并保留原文件，不以空库存覆盖。
异常断电仍可能回退到最近一次保存；这些文件与原版玩家文件没有跨文件事务保证。

## 自动检查与边界

- 四个平台构建并检查 App SPI、独立购买资格、菜单权限相关标识、铁砧回调隔离及 MCphone 购买恢复接口。
- `testPortableMenus` 在四目标检查加工进度冷却、输出容量与溢出边界。
- Fabric 的 `testProcessingState` 使用真实 ItemStack、SimpleContainer 和 Codec，以确定性配方替身检查半程保存恢复、满格阻塞、输入变更、桶余留物、海绵、批量酿造、更换原料、取消事件和原子文件替换。
- Forge／NeoForge 的完整注册表需要加载器启动，不能用普通 JavaExec 代替。上述共享加工状态测试在 Fabric 上运行；四目标会编译同一实现。
- 状态测试不是游戏内联机测试，也不证明第三方配方、GUI 操作或存档生命周期已在实机验收。

## 游戏内验收清单（待完成）

在四个平台分别用匹配版本的 MCphone 与附属测试，客户端与服务端同步更新。

1. 分别购买九类 App，只扣除对应方块；旧已购工作台能够直接打开；未购买／不携带设备无法打开。
2. 织布机制作带图案旗帜，制图台缩放／复制／锁图，砂轮修复和祛魔；测试 Shift、关闭、死亡和换维度，无重复返还。
3. 熔炉投入两份原料及燃料，关闭 GUI 等待后查看产物；检查配方书、Shift 取出、经验球、不同输出与满格阻塞、熔岩桶和湿海绵。
4. 酿造三瓶水→粗制药水→有效药水，测试红石、萤石、火药、龙息及原料余留物；中途换原料、取走全部瓶子后不得继续原批次。
5. 两种机器加工到一半退出，再登录；离线时间不补算。正常停服重启后库存、燃料和进度不丢失。
6. 死亡等待复活、换维度、取走手机、卸载重装、连续重复点击 App；材料不重复、库存不串到另一玩家。
7. 两名玩家同时使用，库存及进度互不影响。背包满时测试取出结果和酿造余留物。
8. 在独立测试存档备份后制造非法加工 JSON；应拒绝打开、记录明确错误且不覆盖原文件。修复后重启再验证恢复。
